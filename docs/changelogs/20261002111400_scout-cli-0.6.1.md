# scout-cli 0.6.1

## Participants

Andrei Makarov

## Decisions

Cut 0.6.1 for crates.io packaging after 0.6.0 published scout_lib without LICENSE or README and blocked CLI publish on the taken `scout` name.

Publish CLI as package `scout-cli` with binary name `scout`. Give scout_lib library keywords and categories. Keep packaging LICENSE.md and README in each publishable package directory.

## Effects

Workspace version is 0.6.1. scout_lib and scout packages include LICENSE.md and README.md. Release tooling publishes `-p scout-cli` and checks crate packaging files. Product CHANGELOG notes the crates.io rename.

## Next

Publish scout_lib 0.6.1 and scout-cli 0.6.1, tag v0.6.1, create GitHub release, fill Homebrew sha256 and AUR updpkgsums. Optionally leave 0.6.0 on crates.io (do not yank) as the first library cut.
