# scout-cli 0.6.1

## Participants

Andrei Makarov

## Decisions

Cut 0.6.1 for crates.io packaging after 0.6.0 published scout_lib without LICENSE or README and blocked CLI publish on taken crate names.

Publish CLI as package `scoutapm-cli` with binary name `scout` (`scout` and `scout-cli` are taken). Give scout_lib library keywords and categories. Keep packaging LICENSE.md and README in each publishable package directory.

## Effects

Workspace version is 0.6.1. scout_lib and scout packages include LICENSE.md and README.md. Release tooling publishes `-p scoutapm-cli`, skips crates already on crates.io for the same version, and checks crate packaging files. Product CHANGELOG notes the crates.io name.
