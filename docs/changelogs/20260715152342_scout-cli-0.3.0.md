## Effects

User-visible scope for 0.3.0:

- `scout_lib` archive module: pull (idempotent ranges, incremental overlap, dry-run), store layout, metrics merge, trace fetch, export formats, diff between stored snapshots.
- CLI split into `cli`, `commands`, `execute`, `archive_cmd`, `batch_cmd`, `diff_cmd`, `completions`, `man`, `exit`, `output`.
- `scout batch`: JSON plan on stdin or `--file`, always JSON report stdout, `--fail-fast`, rejects nested batch and config set/unset.
- Output modes: human plain, script `--plain` TSV, pretty JSON (`-o json`), compact `--json`; `SCOUT_OUTPUT` env.
- Exit codes in `exit.rs` mapped from auth, API, usage, and I/O errors.
- TUI: tab selection, refresh interval, UTC toggle, local timezone display.
- Packaging: Homebrew and AUR install completions and man page from `scout completions` / `scout man`.
