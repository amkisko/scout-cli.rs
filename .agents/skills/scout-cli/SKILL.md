# Scout CLI

Use when querying ScoutAPM from the terminal, scripts, or coding agents.

Read `scout-cli.md` in this skill directory for commands, auth, and output.

## Quick reference

Prefer `scout` commands over raw HTTP. Use `--json` or `scout batch` for agents. Secrets stay in 1Password, Bitwarden, or KeePassXC.
