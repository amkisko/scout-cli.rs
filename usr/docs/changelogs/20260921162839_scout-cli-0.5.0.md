## Effects

Workspace version is 0.5.0. Packaging manifests follow via sync-packaging. CHANGELOG Unreleased bullets moved under 0.5.0 (2026-09-21).

Default archive pull writes app metrics, endpoint and job listings, per-endpoint and per-job series, errors, anomalies, and insights. Traces stay an explicit sample. Metric series accept [timestamp, value] tuples. A refused window is recorded and the rest of the pull continues. The manifest is checkpointed after each resource.
